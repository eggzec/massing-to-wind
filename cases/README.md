# cases/

Generated by the generator agent with `m2w generate cases` (default seed 1). Locked after the M2 gate.
Regenerate with `dotnet run --project src/M2W.Cli -- generate cases`; the test
`Committed_cases_match_the_generator` fails if this folder and the generator ever disagree.

- `_example/case_0007/` is a hand-made format reference matching the example in `AGREEMENT.md`.
  Two blocks, 18 m tall: B01 (20 × 10 m) emitted as six stacked 3 m floors, B02 (10 × 10 m) whole,
  0.3 m gap between them, map coordinates (origin 530000, 180000). Correct repair: one shell, 30.3 × 10 m,
  footprint 303 m², volume 5,454 m³. The generator never touches it.
- `case_0101` … `case_0390` (290 cases) are generated. IDs `case_0001`–`case_0100` are kept for hand-made cases.
  Regenerating deletes only `case_NNNN` folders that contain a `case.json`; anything else here is left alone.
- `index.json` lists every case: seed, kind (`clean`, `single`, `combined`), faults, face style, site, blocks
  and a short note per injected fault (for people; the solver must not read it).
- Hidden cases are kept by the owner outside this repository (`m2w generate ../hidden --seed 90001`).

## What is in the set

| Kind | Count | What |
| --- | --- | --- |
| Clean controls | 10 | 1–4 separate blocks, triangles, local coordinates, closed outward shells, no slivers or short edges. They already meet the output rules (only the object names are `B<nn>`, not `shell_NNN`). |
| Single fault | 12 × 20 | One fault from AGREEMENT.md each. |
| Combined | 40 | 2–4 faults each (about 10 combined cases per fault). |

The order is shuffled with the seed, so a case ID says nothing about its faults.

## How a case is made

1. **Massing.** Footprints in a site's grid frame: bar, L, U, courtyard, tower, tower on podium; extruded floor by
   floor (taller ground floor, 3.0–3.5 m typical floors), with optional setbacks on upper floors (tiers).
2. **Site.** Convex plot (rectangle, irregular quadrilateral, acute-angled trapezoid, corner-cut pentagon), turned
   to a random direction for about two thirds of the cases. Inward setback of 2–6 m. The massing grid follows the
   longest site edge. Groups of blocks are placed inside the setback, at least `max(4 m, 3 × minGap)` apart.
3. **Ground truth.** The corrected model is merged as an exact 2.5D height field. That gives shell count, volume,
   footprint area, height, genus (courtyard holes), mustMerge and mustStaySeparate (blocks in different shells
   within 10 m of each other). Shells are listed largest volume first, each with `blocks` (which blocks it contains)
   and `anchor_m` (a local [x, y] point well inside its footprint, for matching by position; D-017). Footprint is
   the area of the bottom face at z = 0. Nothing is typed by hand.
4. **Faults.** These are applied to the emitted geometry. See the table below and `DECISIONS.md` (D-009 to D-017).

| Fault | How it is injected | Expected answer |
| --- | --- | --- |
| `overlap` | Two blocks interpenetrate: tower through podium, crossing bars, corner overlap | Union, one shell |
| `stackedFloors` | Block emitted as one closed object per floor (`B01_F01` …), coincident floor faces | One shell per block |
| `touchingWalls` | Blocks wall to wall (pair or terrace of three), coincident wall planes, any heights | Union, one shell |
| `smallGap` | Parallel facing walls a gap apart. Half below `minGap` (4 at 0.9×), half above (4 at 1.1×); `minGap` itself varies in some cases | Below: gap filled up to the lower block, merged. Above: separate (`mustStaySeparate`) |
| `sliver` | Thin (angle well below `minAngleDeg`) or zero-area triangles along shared edges; surface stays closed | Unchanged |
| `shortEdge` | Split vertex on an edge (edge < `minEdge`), or a tiny ledge or jog where parts should be flush | Flush design (volume change < 0.3 %) |
| `duplicateVertices` | Faces stop sharing vertices (some or all), some copies nudged within `weld` | Unchanged |
| `openSurface` | 1–3 non-adjacent faces deleted, or the ground face(s) of an object | Unchanged (holes closed) |
| `flippedFaces` | 10–40 % of the faces reversed, or a whole object inside out | Unchanged |
| `floatingBlock` | Whole block lifted by 0.1–0.9 × `groundSnap` | Moved back down (height unchanged) |
| `sunkBlock` | Whole block sunk by 0.1–0.9 × `groundSnap` | Moved back up (height unchanged) |
| `farCoordinates` | Map origin (e.g. 681940, 5883213), sometimes with a site elevation in z | Local coordinates |
